# Man pages

The on-line manual pages are generated automatically from the
[smartmontools source repository](https://github.com/smartmontools/smartmontools)
(`main` branch) when this website is built.

* [smartctl(8)](smartctl.md) — the control and monitoring utility
* [smartd(8)](smartd.md) — the SMART monitoring daemon
* [smartd.conf(5)](smartd.conf.md) — configuration file for smartd
* [update-smart-drivedb(8)](update-smart-drivedb.md) — update the drive database

!!! note
    These on-line pages are generated from the current development version and
    may differ from the version installed on your system.  The manual pages
    installed on your system should be regarded as definitive for your
    installation.
