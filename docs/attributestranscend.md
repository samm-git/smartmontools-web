### Interpretation of S.M.A.R.T. Attributes for SATA Solid State Drives <a id="InterpretationofS.M.A.R.T.AttributesforSATASolidStateDrives"></a>
  
Models: TS(8|16|32|64|128|192)GSSD25S-(M|S)

| **Device Model** | **Attributes ID#** | **Attributes Name** | **Special** | **Description** |
| --- | --- | --- | --- | --- |
|  | 9 | Power-On Hours Count | empty value | Quantity of elapsed hours in the switched-on state. |
|  | 12 | Power Cycle Count |  | Number of complete power on/off cycles of hard disk. |
|  | 229 | Halt System ID, Flash ID |  | Halt System ID and Flash ID |
|  | 232 | Firmware version information |  | Year, month, day, channels, banks of firmware |
|  | 233 | ECC Fail Record |  | Information about ECC fails |
|  | 235 | Erase Count Average, Erase Count Max |  | Erase Count Average and Erase Count Max |
|  | 235 | Good Block Count, System Free Block Count |  | Good Block Count and System Free Block Count |
