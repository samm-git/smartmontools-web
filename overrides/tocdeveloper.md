# Developer information

Smartmontools is developed in the open.  All source code, issue tracking and
pull requests live on GitHub:

- **Source code:** [github.com/smartmontools/smartmontools](https://github.com/smartmontools/smartmontools)
- **Issues & patches:** [github.com/smartmontools/smartmontools/issues](https://github.com/smartmontools/smartmontools/issues)
- **Pull requests:** [github.com/smartmontools/smartmontools/pulls](https://github.com/smartmontools/smartmontools/pulls)

Development happens on the `main` branch; releases are tagged `RELEASE_x_y`.

## Mailing lists

- [smartmontools-devel](https://listi.jpberlin.de/mailman/listinfo/smartmontools-devel) —
  private team list for strategy, release planning and infrastructure.
- [smartmontools-database](https://listi.jpberlin.de/mailman/listinfo/smartmontools-database) —
  contributions of drive information not yet in the drive database.
- [smartmontools-support](https://listi.jpberlin.de/mailman/listinfo/smartmontools-support) —
  support, discussion and bug reports.
- [smartmontools-announce](https://listi.jpberlin.de/mailman/listinfo/smartmontools-announce) —
  release and project announcements.

Archives are available at
[listi.jpberlin.de/pipermail](https://listi.jpberlin.de/pipermail/).

If you notice a problem with the project infrastructure, please
[report it](mailto:smartmontools-devel@listi.jpberlin.de).
